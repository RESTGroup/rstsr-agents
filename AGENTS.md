# RSTSR Project

RSTSR: an n-dimensional rust tensor toolkit (common name), REST rust-based electronic structure toolkit subproject for tensor support (formal name).

## Important notices to AI code agent

- Please follow skill `git-commit-coauthor` when git commit. Code agent is not supposed to automatically commit codes, even given enough permissions (unless user explicitly instructs in session).
- If some large part of code is generated by AI (a whole file or module, or large part of a file), it is recommended to add message like `Most or all contents generated by AI (model [glm-5.2/deepseek-v4-pro/chatgpt-5.6-sol/...])`. Note the model is not related to code agent (Claude/Codex can still use models other than claude/chatgpt, the code agent should double check the model used for code generation).

## Notices to human developers

This project is currently not fully-driven by AI. At current time (2026/08), we notice the strong potential of AI, but we feel this is not fully proven for maintaining such kind of project. We will
- allow full AI usage (weak or no manual review) in testing, FFI binding or C-code translation.
- allow partial AI usage (with manual review) otherwise; we do not seek 100% human involvement, use AI for real but not against AI or treat AI as god.
